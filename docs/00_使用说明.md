# 图片驱动短片工作流 · V1.3

根据一张图片创作40秒以内、无台词无旁白的视觉故事。内容、美术和镜头按输入决定，不限定绘画、摄影、民俗或某种风格。

本包是供多模态AI执行的方法和模板，不是双击运行的视频软件；没有内置API密钥、额度或自动剪辑程序。

核心是引导用户，交付故事、美术、图片提示词、分镜和视频提示词。视频由用户在不同平台手动生成与剪辑；图片则先自检当前环境，有相应能力及已有授权时可以辅助生成，否则交提示词供外部制作。

## 直接复制使用

1. 将 `01_通用主指令.md` 全文作为本次会话或项目指令交给能看图的AI。
2. 上传图片，使用 `02_启动与修改示例.md` 的请求示例。
3. AI先自主判断内容与细节取舍，给至少三条具体建议并标首选；再核对读图结果，必要时选择整体或拆分，确定故事与分镜。
4. 图片按能力选择当前环境辅助生成或外部手动制作；视频提示词由用户复制到不同平台使用，后期按剪辑说明人工完成。

提示词不能替代真实参考图；上传和挂载按实际工具操作。只有文本能力的AI无法核对图片。

## 作为Skill使用

把整个 `image-story-short` 文件夹放入所用工具支持的技能目录，保留内部相对结构。支持该调用语法的工具可使用：

> 用 $image-story-short 根据上传图片设计40秒以内、无台词无旁白的短片，先分析内容与画风，再写故事、美术和分镜。

本次仅制作分发包，没有安装到本机全局技能目录，没有修改任何同事的软件设置。不同宿主如何发现或刷新Skills，以其说明为准。

## 默认流程

读图与必要核实 → 本片美术卡 → 视觉故事 → 拆分判断 → 素材清单 → 导演分镜 → 图片/视频提示词 → 转场与检查。

素材先粗列，分镜后回填镜号与帧计划。缺参考图时标待制作，不阻塞文字交付；未指定视频平台时仍交通用提示词，不要求本环境有视频生成能力。

能力自检看实际工具，不能仅凭模型名称或“多模态”判断生图能力。模型名可靠可知才记录，未知无需先查明。可看图不等于可生图，可生图不等于可编辑参考图。

默认36—38秒，成片小于40秒。按需要集中确认内容理解、拆分选择、故事与分镜；已有答案不反复询问。只改一镜时，仅改该镜与受影响的衔接。

## 素材与转场的新规则

- 每镜用最小必要素材，细节特写不强行加入第二主体。
- 至少三条建议必须结合本图，说明对象、做法、理由、是否生图和优先级；不等于必须拆三份或生成三张图。
- 区分同镜组合、镜内接力与跨镜剪辑，按故事需要选择。
- 多张参考不等于多主体入画；手部、道具和风格图可只服务一个细节。
- 每个切点考虑前镜出口和后镜入口；复杂接点补生成动作、后期切点与备用方案。
- 直接切、动作接切、遮挡、形状匹配、声音桥接均按需使用，不要求全片无缝。
