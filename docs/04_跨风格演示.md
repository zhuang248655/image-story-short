# 跨风格演示

以下均为假设输入，用于演示框架选择；没有实际图片或视频，不是看图准确性或成片效果测试。

## A：水彩动物插画

假设：草地上的狐狸，鼻尖前一片落叶，透明水彩、纸纹、软边缘。

美术：保持狐狸轮廓、耳尖及毛色；薄色层和纸纹，不改成立体毛发。无需第二动物。
故事：风送走叶片，狐狸追到灌木旁；叶子落上鼻尖，它轻吹让叶子继续飞。
拆分：主体清楚时不拆角落；必要时只补叶片细节。

| 时间 | 镜头 | 动作与切法 |
|---|---|---|
| 0—6秒 | 中景 | 狐狸看叶，风起叶片向右飘 |
| 6—13秒 | 侧面中全景 | 狐狸向右小跑，沿方向接切 |
| 13—20秒 | 近景 | 灌木边停步探头，叶片从上方落下 |
| 20—28秒 | 鼻尖特写 | 叶子落稳，鼻尖轻抖；只含必要局部 |
| 28—38秒 | 中景 | 轻吹叶片，停下目送，直接切回中景 |

衔接：落叶运动中切特写，叶片落下只发生一次。无需新增遮挡物或另一动物。

## B：写实空巷照片

假设：雨后石板巷、门边闭合旧伞，没有人物。

美术：保持空间锚点、湿地反射与自然光，不绘画化、不添加路人。不编造地点或作者。
故事：水滴引出水纹，风把伞吹倒；伞短距滑动停在门槛前，云隙光照出倒影。
拆分：不逐个拆建筑，伞结构不清才补道具参考；不默认多角度板。

| 时间 | 镜头 | 动作与切法 |
|---|---|---|
| 0—7秒 | 全景 | 空巷滴水，闭伞静置，建立空间 |
| 7—13秒 | 水面特写 | 水滴落下，水纹扩散，风声先入 |
| 13—21秒 | 门边近景 | 伞带被吹动，伞缓缓倒下 |
| 21—29秒 | 低机位中景 | 接地后短距滑动，不重复倒伞 |
| 29—38秒 | 中全景 | 伞停稳，光变亮，仍无人 |

衔接：水面→伞用风声先入的J-cut；倒伞→滑动按接触阶段接切。若滑动不稳定，改为倒下后静置，保留光线和水滴收尾。

## C：几何拼贴抽象图

假设：米白底、蓝圆片、红窄条、黑矩形，剪纸边缘。

美术：保持平面纸片、有限色彩和边缘纤维，不加人物、真实三维运镜或虚构历史。
视觉故事：红条打破平衡，推动蓝圆；圆片绕开黑矩形，三者形成新平衡。
拆分：独立运动时按三形状分层，无需空街与人物设定。

| 时间 | 镜头 | 动作与切法 |
|---|---|---|
| 0—7秒 | 整体 | 初始排列，红条偏移 |
| 7—14秒 | 接触特写 | 红条触碰圆片，只显示接触区域 |
| 14—22秒 | 整体 | 圆片移开绕过矩形，位置关系可读 |
| 22—30秒 | 局部中景 | 跟随圆片显露矩形，注意力镜内接力 |
| 30—38秒 | 整体 | 三者形成新平衡，运动渐停 |

同镜组合：形状关系就是事件，故整体镜头需要三者；特写不为凑素材硬塞完整矩形。
衔接：构图对应与直接切即可，不让圆片融化成矩形。

## 共同边界

三个演示均为38秒；这不是固定镜数模板。可以有人物、无人物或抽象主体。背景核实、拆分、空境和多素材都按内容需要选择。简单切、动作接切和声音桥接同样能讲故事。
