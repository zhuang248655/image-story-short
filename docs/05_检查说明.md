# 工作流包检查说明 · V1.3

日期：2026-11-03。

## 已完成的检查

- 实际ZIP的内容完整性、UTF-8、内部文件链接、页内锚点和内联文件名均由独立检查脚本复核。
- 通用主指令与技能入口、六份参考逐段同步，不依赖包外文件或本机绝对路径。
- 解出的技能入口与界面配置在打包前经过格式、YAML与UTF-8检查。
- 三个假设演示时间轴连续、无重叠，时长分别为[38, 38, 38]秒。
- 每份文档的HTML注释、技能元数据、界面配置注释及ZIP元信息含署名水印，常规渲染不显示。
- 原有开源方法出处保留；署名针对本包编排与新增内容，不覆盖上游署名。

## 功能边界复核

核心交付是故事、美术指导、至少三条具体取舍建议、素材与分镜表、图片提示词、视频提示词和人工操作单。
视频由用户在外部平台手动制作；本工作流不调用视频生成、提交API或自动剪辑。
图片按可见内容自主判断必要性，并以实际看图、生图和参考编辑能力分别自检；支持且已获授权才辅助生成。
未知模型名、无生图工具、未选视频平台或未回传生成图，不阻塞文字创作包。

## 衔接与指向

素材先粗列、分镜后回填编号；关键帧和动作分别写；转场落实到前后镜正文及人工剪点；
图未做好标待制作，已有图才绑真实附件；当前采用版缺失时只请求必要旧稿；局部修改只扩展到相关接点。

详细修订与自检分支见 [指令衔接自检](06_指令衔接自检.md)。

## 检查边界

本轮没有实际生成图片或视频。演示是方案推演，不是独立模型行为测试或视频效果验证。
外部平台界面、模型能力和技能加载方式未做全平台兼容测试；来源链接不是必需运行依赖。
本包没有发现需要额外加入自动化模块才能完成当前任务的缺口；媒体效果仍取决于实际平台与人工制作。
