# 图片故事短片 · Image Story Short

把一张图片发展成 **40秒以内、无台词、无旁白** 的视觉小故事，得到美术指导、图片提示词、导演分镜、视频提示词和人工制作说明。

适用于摄影、插画、水彩、平面设计、拼贴、传统绘画及抽象图形。内容与视觉规则从输入图片提取，不套用固定题材。

**核心是引导与提示词。** 图片在当前AI确有生图/参考编辑能力且用户已授权时可辅助生成；视频始终由用户在不同平台手动制作。

## 快速开始

### 方式一：直接复制主指令

1. 打开[通用主指令](docs/01_通用主指令.md)，复制全文到能看图的AI会话或项目指令。
2. 上传图片，发送下面的启动语。
3. 根据建议确定故事和必要素材，使用逐镜提示词去自己的图片/视频平台手动制作。

> 根据这张图创作40秒以内、无台词无旁白的小故事。先自检看图和生图能力，再分析图片，自主判断细节取舍，给至少三条具体建议并标首选。然后写美术卡、故事、分镜、图片与视频提示词，说明参考图怎么用以及镜头怎么衔接。视频由我在外部平台手动制作。

### 方式二：安装Skill

解压技能安装包，把完整的 `image-story-short` 文件夹放进你所用工具支持的技能目录，保留 `SKILL.md`、`references`、`agents` 的相对结构。不同工具的技能目录和刷新方式，以该工具说明为准。

支持此调用语法的工具可以使用：

> 用 $image-story-short 根据上传图片制作40秒内无台词短片的故事、美术和分镜提示词；先给至少三条细节取舍建议。视频由我手动制作。

## 工作流程

能力自检 → 图片解读与必要背景核实 → 本片美术卡与视觉故事 → 至少三条具体取舍建议 → 必要的素材拆分/补绘计划 → 导演分镜 → 图片与视频提示词 → 人工操作与转场说明 → 检查和局部修订。

- **至少三条建议不是必须生成三张图。** 可以建议保留整体、裁切重点或不制作无关细节。
- **多张参考不等于多主体入画。** 单一细节特写不硬塞第二个人物或道具。
- **不强求无缝转场。** 按内容选择直接切、动作接切、遮挡、形状匹配或声音衔接。
- **不因缺图阻塞文字交付。** 已完成的提示词可先用，缺失参考列为人工待制作项。
- **不自动生成视频。** 视频平台、上传参考、复制提示词和后期剪辑均由用户处理。

## 维护与发布

仓库内的检查/打包脚本只用于发布技能文件，不调用图像或视频模型，不需要生成平台API密钥。

本地检查：`python scripts/build_release.py --check`。

本地打包：`python scripts/build_release.py`，生成两个ZIP和校验文件。

维护者修改内容后更新 `VERSION` 并推送到 `main`，GitHub Actions会检查、打包并发布对应版本；同版本不自动覆盖，必要时修正后再手动重跑。也可在Actions页手动启动发布。
