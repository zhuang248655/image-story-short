# 美术指导

适用：读图后的视觉分析、素材生成、扩图、补绘与关键帧美术。局部任务只取相关部分。

素材规划先自主判断主次与细节取舍，再给至少三条本图建议，写明对象、处理、理由、是否生图及首选。建议可包含裁切、不拆分、不新增，不意味着必须制作三张图。实际生图按入口的能力自检与人工交接规则执行；视频只交提示词。

## 从可见特征建立美术卡

| 维度 | 观察与决策 |
|---|---|
| 线条与边缘 | 粗细、软硬、勾线、线色、边缘溶解；摄影无需虚构线稿 |
| 色彩关系 | 主色、辅助色与强调色的分布；冷暖、明度、饱和度如何组织主体 |
| 材质与媒介 | 纸纹、颜料、颗粒及实际物体材质；不要把风格纹理变成场景物体 |
| 光影 | 光源方向、软硬与对比；平涂可写“以色块分层，无统一真实光源” |
| 空间 | 摄影透视、等距、散点、平面拼贴或抽象关系；不统一改成三维写实 |
| 造型 | 比例、轮廓、面部、服装、部件及连接；保留风格化形变 |
| 构图 | 焦点、视觉重量、视线动线、层次与负空间；为动作留出空间 |
| 运动 | 按媒介与情绪选择微动、写实运动、有限动画或图形运动 |

色彩可用视觉近似名称；只有实际采样才把HEX称为采样结果，不为凑字段固定色数。

## 三种边界

- 身份与结构：哪些外貌、部件、比例、服装和从属关系不能变化。
- 可动范围：关节、布料、反射、纸片等如何运动，遵循该画面的视觉规则。
- 改编范围：新增角色、环境、光线和补绘位置的原因；新增不是原图事实。

## 参考用途

| 用途 | 负责 | 不自动控制 |
|---|---|---|
| 身份 | 外貌、体型、服装与标志 | 整镜背景和固定构图 |
| 道具 | 部件、材料、连接与尺度 | 无关人物或手势 |
| 场景 | 空间锚点、路径和环境 | 强行把特写拉成全景 |
| 风格 | 色彩、笔触、材质和表现方式 | 复制参考图中的所有对象 |
| 姿态/结构 | 姿势、握持与轮廓 | 无关身份或服装 |
| 首帧/尾帧 | 对应时刻的构图与状态 | 必然保证全程连续 |

逻辑用途不等于API字段，具体绑定按实际工具能力映射。主体参考、姿态图和风格图可以支持同一个细节，不需要将多个主体都放入画面。

## 按需制作资产

- 空境：需交代空间、人物逐步进入或背景复用时制作，普通特写不必准备。
- 人物图：持续出镜且必须辨认身份时准备；清晰已有图优先复用。
- 道具细节：结构、握持、文字或连接决定动作时才准备。
- 设定板：确有多角度需求才扩展，不统一生成。
- 拆分补绘：先认清归属，移除遮挡后恢复合理轮廓；不能遗留被移除对象的部件。
- 画内文字：记录内容、位置和重要性。模糊字不猜；按用户选择保留、后期加字或改纹样，不擅自删除叙事信息。

## 美术卡格式

先用一句具体视觉规则描述本片，再写：保留特征、色彩、光影/空间、构图、运动尺度、新增边界与应避免的偏差。

必要的新场景先做一张定调帧，其余镜头只取该图的色彩、材质和光线，不让定调图锁死所有构图。

修正应能落实到画面，如“保持纸片边缘，向右留出滑入空间”，不用“更高级、更有质感”替代决策。
